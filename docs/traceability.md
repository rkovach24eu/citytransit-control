# Узгодженість проєкту

| Матеріал | Узгодження |
|---|---|
| ПР1 | CityTransit Control та ціль ETA до 2 хв; реалізація звужена до ETA |
| ПР2 | speed, traffic, occupancy, weather, UTC; distance є похідною GPS і геометрії |
| ПР3 | 8 UC, 12 DP, 12 HITL; DP-01–03 збережені з ПР4 |
| ПР4 | C1–C7 / D1–D3; локальні файли замість production-сервісів |
| ПР5 | Ridge baseline + правила; попит і dispatch поза реалізацією |
| ПР6 | Відтворюваний код, notebook, 1600 synthetic rows, 15 cases |
| ПР7 | Три проблемні випадки, правила auto/review/reject та обмеження |

Виявлену розбіжність щодо відсутньої ПР3 усунуто поточною специфікацією; у фінальній схемі використовуються її ID. Раніше запропонований бустинг лишається кандидатом майбутнього порівняння, поточний метод — навчений ridge baseline. Оцінені ПР1–2 не змінено.
